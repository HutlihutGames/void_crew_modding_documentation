# Uploading Mods to Thunderstore
- Go to the [Thunderstore upload page](https://thunderstore.io/c/void-crew/create/)
- Drag and Drop the zip file containing your mod into the page
- Select your Team (or make one if you haven't already)
- Select "Void Crew" under Communities
- Select relevant categories
- Press Submit  


Note that it can take anywhere between 1 and 3 hours for uploaded/updated mods to be visible from mod managers.

```{important}
Thunderstore does not allow you to edit the name of the mod once uploaded.
So we recommend choosing a name that will still be valid for future versions of the mod.
```
